# Blinkit_Sales_Analytics

An end-to-end retail analytics project focused on exploring Blinkit's grocery sales data, understanding outlet performance, and transforming raw data into meaningful business insights using Excel and Power BI.

## Project Overview

This project analyzes grocery sales and outlet-related data to understand sales performance, product distribution, customer ratings, and outlet characteristics. It combines data analysis, business reporting, and interactive visualization to support data-driven decision-making.

The project includes an executive business report, an Excel analytics workbook, and a Power BI dashboard.

## Objectives

- Analyze overall sales performance and key business metrics.
- Identify top-performing product categories and outlet types.
- Compare sales across outlet locations, sizes, and establishment years.
- Examine product visibility, fat content, and customer ratings.
- Develop visual reports that communicate insights clearly.
- Support business decisions through data-driven analysis.

## Dataset Description

The project uses grocery retail data containing product-level sales information and outlet attributes.

Key fields include:

- **Item Identifier:** Unique product identifier.
- **Item Type:** Product category.
- **Item Fat Content:** Product fat-content classification.
- **Item Visibility:** Product visibility within an outlet.
- **Sales:** Sales value associated with the product.
- **Rating:** Customer rating.
- **Outlet Identifier:** Unique outlet identifier.
- **Outlet Size:** Size classification of the outlet.
- **Outlet Location Type:** Outlet location tier.
- **Outlet Type:** Type of retail outlet.
- **Outlet Establishment Year:** Year the outlet was established.

The dataset supports comparisons across products, categories, and outlet characteristics.

## How to Use This Project

### Prerequisites

- Microsoft Excel
- Microsoft Power BI Desktop

### Steps

1. Clone or download this repository.
2. Open `Dataset.xlsx` to inspect the source data.
3. Open `BlinkIT_Grocery_Analytics.xlsx` to explore the Excel analysis.
4. Open `Blinkit Statistics.pbix` in Power BI Desktop to view the dashboard.
5. Open `BlinkIT_Executive_Business_Report.pdf` to review the executive report.

If you modify the source dataset, refresh the relevant queries and visuals in the associated files as needed.
